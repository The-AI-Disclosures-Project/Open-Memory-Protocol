# History

OMPI grew out of AI Disclosures Project work that began in August 2025; this repository, opened in August 2026, is where that work converges.

- **August 2025** — "Protocols and Power" (Moure, O'Reilly, Strauss) is published as an SSRC working paper. It sets out the case for open protocols in AI infrastructure. Available at [ai-disclosures.org](https://www.ai-disclosures.org/assets/papers/Protocols-and-Power-Moure-OReilly-Strauss_SSRC_08272025.pdf).
- **October 3, 2025** — ["The Memory Walled Garden"](https://asimovaddendum.substack.com/p/the-memory-walled-garden) is published on *Asimov's Addendum*, the initiative's first public position on portable AI-agent memory. Archived in [`the-memory-walled-garden/the-memory-walled-garden.md`](the-memory-walled-garden/the-memory-walled-garden.md).
- **April–May 2026** — Rockefeller Foundation Bellagio convening on *Human + AI Markets*. Twenty leaders across AI labs, memory-infrastructure providers, and civil-society organizations discuss agent-memory portability.
- **May 2026** — First public commits on the ACP-based memory-server prototype ([`SrulyRosenblat/agent_memory_mcp`](https://github.com/SrulyRosenblat/agent_memory_mcp)), covering session indexing across twelve coding-agent harnesses. Now imported here as [`prototypes/acp_memory_server/`](../prototypes/acp_memory_server/).
- **June 2026** — FOO Camp session (O'Reilly Media, Lighthaven Berkeley) on coding-agent memory portability.
- **August 2026** — Charles Packer (Letta) circulates the draft OMP specification, [`working-group/past-proposals/draft-v0.2-packer.pdf`](../working-group/past-proposals/draft-v0.2-packer.pdf); it fed the editors' drafts that followed.
- **September 9, 2026** — First ecosystem convening, co-hosted with Mozilla and IBM; thirteen external participants from ten affiliations.
- **September 28, 2026** — Exchange-and-runtime call. The contributed proposals are compared in the [common-ground notes](../working-group/exchange-and-runtime/2026-09-28-common-ground.md).
- **October 2026** — In-person gathering at the O'Reilly open-source unconference (Berkeley). Editors' draft v0.1 (October 2) and v0.2 (October 14) of the exchange-and-runtime working specification.
- **November 6, 2026** — Editors' draft v0.5 of the [exchange-and-runtime working specification](../working-group/exchange-and-runtime/2026-11-06-working-spec-v0.5.md) is merged ([PR #13](https://github.com/The-AI-Disclosures-Project/Open-Memory-Protocol/pull/13)).

Entries without a link are dates from the project team; this repository holds no notes for them.
