# Open Memory Protocol documentation

Start with the current working draft, then choose a proposal or implementation relevant to your task. This repository is the technical and governance home of the Open Memory Protocol Initiative; an editors’ draft is not an adopted protocol.

| What you need | Where it lives | Status |
| --- | --- | --- |
| Current memory object and exchange/runtime work | [Editors’ draft v0.5, November 6, 2026](../working-group/exchange-and-runtime/2026-11-06-working-spec-v0.5.md) | Working draft; includes agreed, proposed, and open items |
| Working-group background | [September 28 comparison and common ground](../working-group/exchange-and-runtime/2026-09-28-common-ground.md) | Background notes |
| Earlier inputs and proposals | [early-draft-specs/](../early-draft-specs/) | Historical drafts and contributed proposals; read their individual status |
| Runnable community examples | [Implementation directory](implementations.md) | Independently maintained, experimental implementations |
| In-repository experiments | [prototypes/](../prototypes/) | Prototype code with its own setup instructions |
| Contributing | [Contributor guide](contributing.md) | Feedback, implementation findings, and working-group participation |
| Governance and adoption decisions | [GOVERNANCE.md](../GOVERNANCE.md) | Initiative decision process |

The v0.5 draft identifies individual-memory requirements and marks remaining manifest and runtime questions. An implementation may choose concrete envelopes or API bindings to make an experiment runnable. Those choices do not become protocol requirements simply because the example works.
