## Agent Memory System Card (AMS Card)

A structured documentation format for agent memory systems, developed by [Mila](https://mila.quebec/) and [Mozilla](https://mozilla.org).

Model cards made language models legible. Dataset cards did the same for training data. Memory systems have no equivalent, despite memory being the component that determines what an agent knows about a person and what it discloses on their behalf.

The template, a completed reference card, and an evaluation framework scoring performance and privacy on separate axes are here:

**https://github.com/mila-iqia/agent-memory-system-card/**

Draft, and open for comment.
